Sky Courier — Meridian Run is a 3D chase-view flight game over a living archipelago: fly a courier plane through glowing rings, collect sky coins, dodge storm balloons, manage fuel and hull, and land on the strip across six missions from a calm lagoon loop to a night mail run and a mountain pass.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Fly with the arrow keys (pitch and bank), W/S for throttle, Shift for boost, P to pause, M to mute. The game runs entirely offline from its own files.
